# 题灵智库管理系统（后台）用户操作手册

> 适用对象：管理员、班主任、科任教师  
> 系统地址：`https://quizwiz.cn`

---

## 1. 系统概述

题灵智库管理系统用于学校/机构教学管理，核心能力包括：

- 教师账号与角色权限管理
- 班级、学生、科任教师管理
- 题库建设与批量导入
- 考试创建、发布、结束与重开
- 学情分析与预警处理
- 资料上传、下载与可见范围控制
- 操作日志审计与系统参数配置

---

## 2. 角色与权限

### 2.1 管理员（admin）

- 可访问全部功能模块
- 可管理教师账号
- 可查看操作日志
- 可修改系统参数

### 2.2 班主任（class_teacher）

- 管理本人负责班级的数据
- 可管理班级、考试、资料、学情

### 2.3 科任教师（subject_teacher）

- 访问本人任教班级/科目的数据
- 参与题库、考试、学情相关流程（受权限范围约束）

> 说明：兼任多角色时，可见数据范围按并集合并。

---

## 3. 登录与安全

### 3.1 登录步骤

1. 打开 `https://quizwiz.cn`
2. 输入手机号与密码
3. 点击“登录”

### 3.2 安全建议

- 首次登录后立即修改默认密码
- 管理员账号避免多人共用
- 定期修改密码
- 发现异常登录及时查看操作日志

---

## 4. 首页（概览）

首页展示真实统计数据（无数据时显示 0），主要包括：

- 班级数/任教班级数
- 学生总数
- 平均提交率
- 待批阅答卷
- 进行中考试
- 题目总量

并提供：

- 班级维度统计表
- 近期成绩趋势图
- 待办提示
- 快捷入口（班级、考试、题库、资料、学情）

---

## 5. 班级管理

### 5.1 班级列表

查看班级名称、年级、人数、邀请码状态等信息。

### 5.2 创建班级

1. 点击“新建班级”
2. 填写班级名称与年级
3. 提交后系统自动生成邀请码

### 5.3 邀请码与入班设置

可配置邀请码是否启用、有效期、是否审核入班。

### 5.4 学生管理

在班级详情中可新增、查看、移除学生。

### 5.5 科任教师分配

可按班级添加/移除科任教师，并关联科目。

---

## 6. 题库中心

### 6.1 查询与筛选

支持按科目、题型、关键词筛选题目。

### 6.2 新增/编辑题目

维护题干、选项、答案、解析、难度、知识点。

### 6.3 Excel 批量导入

1. 下载模板
2. 按模板填充
3. 上传预览
4. 修正后确认导入

### 6.4 批量操作

支持批量修改属性、批量删除（进入回收站）。

### 6.5 质量巡检与修复

支持识别并修复常见题目结构问题（如选项缺失、答案不匹配等）。

### 6.6 回收站与历史版本

- 回收站：恢复或彻底删除
- 历史版本：查看并恢复旧版本

---

## 7. 考试管理

### 7.1 列表与状态

考试按“未开始/进行中/已结束”分类，支持分页。

### 7.2 创建考试

1. 填写标题、时间、时长
2. 选择科目与班级
3. 选择题目并设置分值
4. 保存

### 7.3 编辑/复制

- 未开始考试可编辑
- 支持复制已有考试快速创建新考试

### 7.4 发布/结束/重开

- 未开始考试可发布
- 进行中考试可提前结束
- 已结束考试可重开

---

## 8. 学情分析

### 8.1 查询条件

支持按班级、科目、时间范围筛选分析数据。

### 8.2 主要分析内容

- 班级成绩分析
- 成绩趋势
- 题目洞察
- 学业预警列表与概览

### 8.3 预警处理

1. 查看待处理预警
2. 填写处理记录
3. 提交后更新状态

---

## 9. 资料库

### 9.1 上传资料

填写资料信息并上传文件，可设置可见班级范围。

### 9.2 列表管理

支持分类筛选、关键词搜索、分页浏览。

### 9.3 可见范围控制

可设置全部可见或指定班级可见。

### 9.4 下载审计

资料下载行为可被记录，用于审计追踪。

---

## 10. 教师账号管理（管理员）

管理员可进行：

- 查看教师账号列表
- 新增教师账号
- 调整角色
- 启用/禁用账号

---

## 11. 系统设置与操作日志（管理员）

### 11.1 系统设置

可配置考试默认参数、预警规则参数等。

### 11.2 操作日志

可按操作人、时间、操作类型、关键词进行查询审计。

---

## 12. 常见问题

### 12.1 登录失败

- 检查手机号与密码
- 检查账号状态是否禁用

### 12.2 页面提示 `Load failed`

- 强制刷新浏览器（`Ctrl/Cmd + Shift + R`）
- 检查网络请求状态与后端健康检查

### 12.3 证书或域名异常

- 检查 DNS 解析（A/AAAA）
- 检查 `80/443` 端口是否放通
- 检查 Nginx 与 Certbot 状态

---

## 13. 日常运维常用命令（管理员/运维）

```bash
# 查看服务状态
pm2 list
pm2 logs quizwiz-api --lines 100

# 重启后端
pm2 restart quizwiz-api

# 更新发布
cd /srv/quizwiz
git pull
cd /srv/quizwiz/teacher-admin
npm install
npm run build
pm2 restart quizwiz-api
systemctl reload nginx

# 健康检查
curl -i https://quizwiz.cn/api/health

# Nginx 检查
nginx -t
systemctl reload nginx
```
