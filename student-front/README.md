## 登录与入班流程（备案合规）

1. **浏览**：未登录可打开全部 Tab 与子页面（首页、刷题目录、学习、我的、错题本、考试列表等），不会被强制跳转登录。
2. **刷题**：仅在组卷/开始做题时要求**登录**；若已登录但未入班，引导前往「我的 → 加入班级」。
3. **入班**：在「我的 → 加入班级」弹框填写**真实姓名 + 班级邀请码**（与此前逻辑一致）。
4. **数据展示**：
   - 未登录：各页可浏览，个人/班级数据提示登录后同步。
   - 已登录未入班：**个人刷题统计**正常展示；**班级考试、班级排名、班级资料**等显示「未加入班级暂无数据」。
5. **公开浏览接口**（无需 token）：`GET /api/public/catalog/subjects`、`knowledge-units`、`unit-detail`。

登录页：点击「确认登录」后返回上一页（若从子页进入）。
